# Game mode artwork

Original images generated for Football Genius on 2026-10-16. No assets were extracted, traced, or cropped from the supplied reference screenshot. The generated originals were resized and encoded as WebP for delivery.

- hero: football, tactics clipboard, blue paint and stadium
- scoreline: blue stadium scoreboard
- matrix: golden player puzzle grid
- duel: fictional footballers facing off
- journeyman: football passport and travel map
- higher-lower: fictional player cards and market arrows
- tunnel-talk: press microphone and quote card
- scramble: floating wooden letter tiles
- pixel-pitch: original retro pixel football scene

These illustrations are decorative. All headings, badges, category filters, rewards, and navigation are implemented separately in the page.
